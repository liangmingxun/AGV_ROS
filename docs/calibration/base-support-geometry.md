# 驱动轮轴中点与圆盘支撑几何冻结记录

## 坐标定义

- `base_link`：左右驱动轮旋转轴线中点，`+X` 朝小车正前方，`+Y`
  朝左，`+Z` 向上。
- `support_link`：顶部 42 步进电机轴线与圆形转盘中心的交点。
- 转盘角度不是静态支撑几何的一部分；当前不控制步进电机，也不发布
  `turntable_link` 动态角度。

## 测量与 CAD 证据

- 机器人旧几何中心到转盘中心：`67.52 mm`。
- 机器人旧几何中心到左右驱动轮轴线：`49.69 mm`。
- 转盘位于驱动轮轴线后方，因此
  `x=-(67.52-49.69) mm=-17.83 mm`。
- 横向中心面对齐：`y=0`。
- `support_link` 坐标轴按约定与 `base_link` 平行：`yaw=0`。
- SolidWorks AP214 完整装配 STEP 中，转盘与 42 步进电机装配基准
  相距 `57.000 mm` 且位移完全沿同一轴线，验证两者平面中心同轴。

冻结平面参数：

```yaml
base_to_support: {x: -0.01783, y: 0.0, yaw: 0.0}
```

`57 mm` 是零件装配基准的轴向间距，不作为 `support_z` 测量值。当前
启动文件将 `support_z=0` 明确作为二维控制占位值；在实测驱动轮轴参考
高度到转盘接触面的高度前，不得把它解释为三维机械高度。

## 三圆盘直接承载的适用边界

三辆小车各自的圆形转盘可以共同支撑一个公共刚性物体，软件仍把三个
圆盘中心作为载荷坐标系中的固定 `q_i`。成立条件是：

1. 物体相对三个圆盘中心不发生平面平移滑动；
2. 三个接触位置可重复布置并在实验前后复测；
3. 物体轻载、低重心，三个圆盘上表面共面；
4. 步进电机角度不作为当前控制量；
5. 摩擦直接承载只用于低速预实验，正式实验必须通过防滑标记位移和
   刚体拟合残差门槛。

圆盘上应使用高摩擦材料并设置位置标记；若断电步进电机的齿槽力矩
导致明显扭转约束，应改为可被动转动但不允许平移滑动的机械结构。
