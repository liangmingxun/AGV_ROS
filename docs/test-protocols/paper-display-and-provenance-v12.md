# 统一绘图与实验追溯 v12

2026-09-13 修正。仅改变分析、录制元数据和测试夹具，不修改控制增益、
轮速尺度冻结参数、物理包络、同步/队形门槛或任何历史 bag。

## 复验与论文追溯

Stage-D 必须完整包含 0.06/0.08/0.10 m/s，正反向各两轮，共12段。
缺少整组速度、整轮、重复段、方向/速度符号错误或非法阈值均不通过。
这不要求重新做已经完整且有效的物理复验。

论文模式必须在原实验目录核验 config_hashes 中记录的冻结配置、三车
底盘配置和 rosparams.yaml：文件存在、路径属于该目录、SHA256匹配。
冻结ID、状态、三车接受标志以及四个command/feedback scale必须与
底盘配置和各车运行参数一致。不使用当前工作区配置冒充历史运行配置。
没有Stage-D证据的旧实验仍可用诊断模式查看，不补写冻结ID使其通过论文模式。

## 实际载荷坐标

CooperativeState与PathReference的frame_id写入原始CSV。
实际载荷测量须与参考处于同一精确坐标系；否则须提供运行时确定并归档的
SE(2)变换，不能根据误差大小临时拟合或逐帧改动：

```yaml
source_frame: world@0000007b
target_frame: three_car_path
x: 0.0
y: 0.0
yaw: 0.0
```

上例仅说明字段格式，不是可直接使用的标定值。
experiment.launch的measured_payload_world_to_reference接受该YAML映射；
录制器将它写入payload.world_to_reference，并在rosparams.yaml中归档。
论文模式要求元数据中的变换与归档运行参数一致。源epoch改变、坐标不匹配、
姿态非有限/零四元数时，实际载荷字段为NaN，并记录alignment_status。
有载论文模式不允许在有效统计区间静默丢弃缺失的独立载荷测量。
独立bag_to_csv.py也支持--measured-payload-transform 指定归档变换YAML。
无载继续使用明确标注的虚拟等效载荷，不将其冒充实际载荷。

## 绘图规范

自动run图与论文对比图共用display_profiles.py和paper_axis_defaults.yaml。
后者保留工程对照组200716冻结的几何误差坐标轴。另增的下层控制器诊断
使用明确的固定展示包络，不宣称是米制几何误差或由工程组推导的范围。

两套入口都保存plots_raw和plots_smoothed_0p8s，PNG/PDF分开存放。
论文对比入口在各实验输出目录下创建这两个子目录。题注一致，实际路径
类型来自归档配置，不写死“S路径”，不在题注后追加滤波窗口。
优化版对实测曲线/误差采用同一0.80秒展示趋势及25Hz绘图抽样；
需求、执行命令、参考及能力边界不做展示滤波。原始版不做趋势滤波。
NaN断点不填补，抽样时保留断点。CSV与指标始终使用未平滑样本。
每幅论文对比图记录轴包络、超出范围样本数及展示参数；超出固定包络
只告警，不裁剪原始数据或更改指标。局部轨迹放大图保留其明确的局部视野。

## 回归

覆盖完整性、文件缺失/哈希与运行尺度不一致、坐标变换/epoch不一致、
原始与优化图的相同刻度/题注、命令不滤波、缺失断点和历史bag兼容。
录包fake夹具显式提供ExperimentState，在recorder armed后才允许假平台
运动；它声明20mm短录包验证目标，不改变正式实验1m或圆形任务门槛。
测试只在隔离ROS master运行，不发送实车指令。
