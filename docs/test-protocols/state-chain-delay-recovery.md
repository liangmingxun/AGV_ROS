# 状态链延迟与恢复修正

适用于无载三车视觉融合链。不得把本修改视为无线延迟已消除或
实车顿挫已完全解决；先完成以下验证，再冻结参数。历史 bag/CSV/图不修改。

## 机制

- odom 消息通过 MessageEvent 记录 ROS 接收时间及回调开始时间。
- 视觉在源测量时间对应的 odom 插值位姿上修正，再传播至最新 odom。
  新视觉领先于已收到的 odom 时暂存，等 odom 到达再修正。
  超出 100 条历史范围或跨越超限 odom 间隔的校正不混用。
- 连续旧 odom 仍累计；融合源时间年龄超过 50ms 时不发布其位姿。
  odom 非递增不处理；真正的 odom 时间缺口重置融合初始化，等待视觉重锚。
- 估计器在投影/差分前拒绝源时间过期的融合输入，默认
  maximum_live_fused_pose_age=0.05s。原同步 slop、快照保持及失效停车保留。
  此新增实时输入策略会拒绝以前可能被接受的旧补到消息，不能冒充旧行为。
- 串口控制短暂使用最后有效状态或状态测量时间前跳超过30ms时，
  启用恢复轮速发布 slew 0.30m/s²，至少250ms且持续至追上目标。
  仅发布端处理；原始需求、上层边界、超限统计不更改。
  安全/终点零速直接发布并清除恢复历史，不受 slew 延迟。
- 发布上限仍±0.16m/s，非有限需求/电压/通讯/队形硬门及终点停车不放宽。

## 录包诊断

两类录包配置均新增三车 fusion_timing / estimator_timing。
Float64MultiArray 没有 Header，通过内嵌源时间关联，不用 bag 写入时间
冒充融合发布时间。fusion_timing 字段依次为：odom序号、源时间、ROS接收时间、
回调开始、发布前时间、实时年龄门通过标志、回调排队时间。
通过年龄门不等于一定发布位姿，初始化/视觉有效门仍需通过。
estimator_timing 字段为：融合序号、源时间、估计器回调时间、源年龄、实时年龄门通过标志。

只读查看新 bag：

```bash
python3 src/multi_agv_control/test/inspect_state_chain.py /absolute/path/to/new.bag
```

source→receipt 大说明融合输入连接延迟；receipt→callback 大说明回调排队；
callback→publish 大说明融合计算耗时；publish→estimator callback 大说明
融合输出传输或估计器回调排队，后两项仍不能仅靠该差值彼此区分。
检查脚本只输出统计，不修改 bag。

## 验证顺序

### 20260912：相机位置校正与运动速度解耦

173106 的 agv1 警告不是丢帧：融合位置在8.028ms内向后校正约5.1mm，
旧位置差分将其误认为约-0.64m/s，触发单次路径状态重同步。
此事件与后续M2a降额造成的80mm队形硬门终止是不同原因。

融合器新增 `/pose_provider/agvN/base_motion_fused`（nav_msgs/Odometry），
在同一消息中携带融合绝对位姿和原底盘odom的实测车体系twist。
它不是执行速度参考，也不是位置校正的差分。原PoseStamped输出保留。
共享三车相机配置启用 `use_fused_motion_velocity`；该模式只订阅新消息，
不在新话题缺失时偷偷回退到旧差分。估计器按车体朝向、支撑点旋转偏置、
最近点投影的曲率/尺度映射计算路径速度；虚拟载荷运动通过三车实测
支撑点速度的刚体最小二乘计算。位置与进度仍来自融合测量，校正不被抹掉。
原速度低通参数、时间/同步门槛、发布限幅、队形硬门均保持不变。
实测速度非有限或超过原0.5m/s状态门仍拒绝；新运动模式另允许每次
进度位置校正最多25mm（叠加原速度与采样间隔允许的位移），超出仍拒绝。
这不能消除真实轮速波动或真实长中断，不以取消告警掩盖链路异常。

录制清单新增三条原子运动话题，转换器单独保存到
`converted/fused_motion.csv`，不混入原底盘odometry.csv或算法状态CSV。
新后处理版本为paper_run_pipeline_v10_atomic_fused_motion_routing。
历史bag/曲线不按新运动来源重新标注。新M1/M2a配对必须使用同一版本。
Robot1必须重启融合器和路径估计器；Robot2/3底盘不变。

1. Robot1 编译并重启底盘/视觉一体入口，避免旧融合进程继续运行。
   Robot2、3底盘代码未改，不要求重新编译。不要重复启动独立视觉脚本。
2. 按现有流程重新建立30cm队形，通过圆形配置下的三车只读门槛。
3. 用当前 M1 reference_v1、0.10m/s、0.75配置跑一次；不同时改增益/降额。
   保留完整启动日志及原始 bag，原始与趋势图继续分开保存。
4. 核对校验、原始轮速、状态年龄、积压抑制及恢复斜率；重点比较
