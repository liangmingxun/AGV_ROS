# 起点有符号进度修正

151701/151948 的 Robot1 初始支撑点沿起点切线分别约为 -8.46/-10.21 mm，
原投影仅在 [0,L] 搜索，进度与初始偏置均被截为 0。初始偏差因此进入启动
跟踪误差，导致同一启动参数在不同摆放下的表现不一致。

三车闭环 overlay 新增 signed_start_extension=0.025 m。每车支撑轨迹在
原起点前增加有限的切线段；内部投影坐标平移 25 mm，发布时减回该平移。
原路径 s>=0 的几何、长度和终点不变。原始 robot/support 位姿不修改，
仅路径进度现在能够表达负值。等效载荷原点投影不扩展。

原控制器按静止样本平均记录有符号进度起始偏置，再从实际进度中扣除。
CSV 转换同样使用录制的偏置，不重新估计原点。几何位置、队形残差和
支撑点误差保留；这不是把初始变形从所有指标中删除。

参数默认 0，旧配置继续保持原行为；启用要求融合实测速度和自动路径锚定。
延伸长度不能超过 25 mm；落在延伸段后方的观测被拒绝，不作外推或旧状态
保持。现有定位距离、初始队形、运行变形、时间新鲜度和轮速安全门不放宽。
120 ms 实测运动外推机制以及冻结的启动参数保持不变。

历史 bag/config/metrics 不重写。新旧进度定义不同，比较历史 Figure7 时
应注明起点截断差异，不能把修正后的坐标变化直接声称为实际运动性能提升。
Robot1 编译中央状态节点后重复同条件无降额 M1；Robot2/3 不需同步编译。
验证初始负进度是否被正确记录、穿过 s=0 时是否连续，然后进入降额配对。
