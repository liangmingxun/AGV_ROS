# Task 15 实际位置与轨迹精度验收

状态：**未执行，所有阈值待预注册。**

## 1. 软件输出的坐标含义

当前Windows端使用四个固定、共面、有效边长150 mm的地面码在线求解
`world_T_camera`。ID 8中心为原点，ID 8→11为`+X`，ID 30位于从相机
向下看时该有向线的左侧并定义右手系`+Y`，`+Z`从地面指向相机。

Windows只输出80 mm车载码的`world_T_tag`。Robot1 Task 15应用实测
`tag_T_base_link`，分别发布车体raw和因果filtered位姿；路径状态估计器再
计算支撑点位姿、S路径进度和速度。米制比例来自地面码有效边长，不需要
预先输入四个地面码的世界坐标。该坐标是“相对于四个固定码”的实际米制
坐标，不自动等于实验室已有坐标。

## 2. 测试前必须冻结的参数

- 相机内参、畸变系数、标定图像尺寸、镜头焦距/对焦/ROI；
- 地面码有效黑边长度及平整度，ID 8/11/15/30的固定方式；
- 三台车码中心高度225 mm的测量记录；
- 三台车各自完整`tag_to_target_x/y/yaw`及测量不确定度；
- 载荷码高度和`tag→load`变换；未完成时载荷保持disabled，不能验收正式载荷轨迹；
- confidence、超时、最大残差和遮挡排除阈值；

## 3. 独立验收步骤

1. 生成Windows清单并归档：配置快照、配置SHA和四个发送器源码SHA。
2. 地面锁定后确认`/vision/aruco/calibration_epoch`非零，四路
   `/camera/world/*_tag_pose.header.frame_id`均为相同的
   `world@xxxxxxxx`且在本轮保持不变。
3. 使用不参与在线求解的独立尺量，核对至少三条不同方向、不同位置的已知
   地面距离。在线拟合残差不能替代这一步。
4. 每台车在覆盖工作区中心、四角和S路径曲率较大区域的多个静止点重复采样。
   分别计算raw车体位置/航向的偏差、RMSE和最大误差；不要用filtered结果掩盖
   固定偏差。
5. 停止并重新启动Windows程序，至少重复三次地面重锁；在相同物理点比较
   重锁间坐标。每次运行单独记录代次，不把多个代次拼成一条轨迹。
6. 让每台车沿独立标出的直线和完整S路径低速运动，比较raw轨迹的尺度、
   横向误差和航向；另行报告filtered轨迹的噪声改善与因果延迟。
7. 单独遮挡AGV1/2/3，确认只对应流失效；恢复后的第一条filtered位姿应从
   当前测量重新初始化。移动相机或固定码触发重新锁定时，Task 17必须判废本轮。
8. 载荷标定完成后重复载荷静态/动态步骤，并确认载荷是独立实体而不是
   “第四台机器人”。在此之前正式实验2a/2b/3的载荷真值门保持关闭。
