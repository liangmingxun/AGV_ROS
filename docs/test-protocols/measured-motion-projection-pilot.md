# 有界实测运动外推候选版

针对旧同步快照重复使用、恢复后进度跳变的问题，三车闭环状态节点将已接收的
原子融合位姿与实测底盘 twist 外推到本次控制时刻。使用恒定实测 body twist
积分位姿，路径进度使用实测路径速度一阶外推。不是电机响应模型，也不使用
期望轮速预测车辆。默认关闭；三车闭环 overlay 启用 0.12 s 上限。

原始 robot/load pose stamp 保留，外推不会延长源数据新鲜度。入口原有 50 ms
过期融合消息拒绝机制、20 ms 三车同步、初始队形和运行硬门、发布限幅均保留。
旧同步快照只有全部源测量年龄在 120 ms 内才允许外推；超限或非有限速度使
状态无效，沿用控制器原有短时保持及 fail-zero。350–470 ms 链路停顿仍会停车。

新增 `/multi_agv/state_projection_timing`，转换到 `state_chain_timing.csv`。
布局为 `stamp,enabled,held,3x(source_stamp,age,projected,measured_s,measured_speed)`。
`aligned_samples.csv` 新增每车源时间、年龄、外推/旧同步快照标志和测量时刻
对齐进度误差。测量时刻诊断误差使用原始 measured_s 减去控制器起始偏置，
再减去源时间之前最近一条公共进度参考；不插值未来参考。

`summary_metrics.json` 的 `state_timing_diagnostics` 单独统计有效运动样本；
每个源测量时间只计一次，避免重复快照增加权重。原来的 Figure7 和任务误差
统计定义不变，不能以测量时刻诊断误差替代任务跟踪误差。

本次不继续调整缓启动参数，不改变 Robot2 降额比例，也不改三车底盘启动脚本。
Robot1 编译并重新启动中央状态节点即可；Robot2/3 不需同步或重新编译。

下一次先在原有安全确认下跑无降额 M1 0.1 m/s 配置，检查是否存在状态无效、
源年龄超过 120 ms、恢复后的跳变。通过后再跑同条件的降额配对。若再次发生
长时停顿，应在运行阶段两端抓包定位独立 TCP 链路；本候选不声称修复其根因。
